# 簡報圖片圖庫更新

Expo／Talk 為同一份簡報與 Pages 部署。保留 38 個非頁尾浮水印圖片來源，改用完整 Ramka viewer：底部縮圖、相鄰預覽／單張切換、縮放、原生滑動與下拉關閉。原投影片鍵盤在 viewer 開啟時暫停，關閉後恢復，避免看照片時誤翻投影片。

Runtime 來源：brand-cis commit `5bdd897cb55654520384de35fe8b01c11bde0e2b` 的 `components/ramka-lightbox/`，鎖定 Ramka 0.0.2。Standalone 帶有 React 19.2.8，入口 1,335 bytes gzip，所有 JS／CSS 分塊 gzip 加總 116,759 bytes（不含圖片），按需載入；不宣稱比原本幾行自製遮罩小。

驗收：`python3 scripts/build-public.py`；共用 `qa/static.cjs` 驗證 38 張縮圖、相鄰預覽、鍵盤只換圖不翻簡報、關閉後簡報導航恢復、縮圖跳轉、檢視切換、放大後控制鈕、Escape 與焦點回復。430 px CDP 模擬滑動／pinch／下拉關閉；reduced-motion 並停用 View Transitions 的降級可開關；隔離 headless Brave 無 uncaught error。實體手機、Safari、VoiceOver 待驗。

公開邊界仍為 public-files.json → dist；新增資產只含完整發行檔及 license，不公開 package／source／sizes.json。runtime 改版須整組重建並更新 script query。還原：revert 本次遷移 commit，master 自動部署；兩個網域、內容、canonical 與簡報其他模式不需變更。
